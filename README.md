# CYBER STRIKE // تاکتیکال شوتر آنلاین و شبکه محلی (LAN Multiplayer)

بازی شوتر تاکتیکال تحت شبکه با قابلیت بازی چندنفره بر روی کابل شبکه (LAN / Ethernet) یا وای‌فای، همراه با هوش مصنوعی موج‌های دشمن (PvE) و مبارزه رودررو و تیراندازی به یکدیگر (PvP / Friendly Fire).

---

## 🚀 نحوه اجرای بازی و اتصال بازیکنان

### ۱. اجرای سرور روی سیستم میزبان (Host)
در پوشه بازی ترمینال را باز کرده و دستور زیر را اجرا کنید:
```bash
npm start
# یا:
node server.js
```

پس از اجرا، سرور به طور خودکار آدرس‌های شبکه شما را شناسایی و چاپ می‌کند:
```
==========================================================
🎯 CYBER STRIKE // LAN & ONLINE MULTIPLAYER SERVER
==========================================================
Local Access:        http://localhost:3000
LAN Network Address: http://192.168.1.33:3000
==========================================================
```

### ۲. اتصال سایر بازیکنان (روی کابل شبکه یا Wi-Fi)
- دوستان شما که با کابل به همان شبکه یا مودم وصل هستند، کافیست مرورگر خود (Chrome، Edge، Firefox) را باز کنند و آدرس شبکه شما را وارد کنند:
  ```
  http://192.168.1.33:3000
  ```
  *(همچنین دکمه «COPY LINK» روی صفحه شروع بازی وجود دارد که لینک را فوراً کپی می‌کند).*

## 🎮 قابلیت‌های شبکه و گیم‌پلی

1. **PvPvE (همکاری + مبارزه با یکدیگر):**
   - **PvE:** تمام بازیکنان همزمان با موج‌های مختلف ربات‌های سایبورگ، استاکرها و تانک‌های جاگرنات مبارزه می‌کنند.
   - **PvP (Friendly Fire):** گلوله‌ها به بازیکنان دیگر هم اصابت کرده و دمیج وارد می‌کند! اگر به هم‌تیمی خود تیراندازی کنید، آسیب دیده و حذف می‌شود.
   - **سیستم ریسپاون تاکتیکی (Respawn):** در صورت حذف شدن، بعد از ۴ ثانیه با ۱۰۰٪ جان و یک سپر محافظ انرژی ۲.۵ ثانیه‌ای (Force Field) دوباره به بازی برمی‌گردید.
2. **شخصی‌سازی اپراتور:**
   - انتخاب نام مستعار (Callsign)
   - انتخاب رنگ تاکتیکی ویزور و تفنگ (۸ رنگ نئونی: Cyan, Green, Amber, Crimson, Purple, Pink, Blue, Yellow)
3. **همگام‌سازی چراغ‌قوه و اتمسفر تاریک (Tactical Flashlight):**
   - نور چراغ‌قوه سلاح تمام بازیکنان زنده در محیط به شکل همزمان پخش می‌شود و راهروهای تاریک را با هم روشن می‌کنید.
4. **رادار تاکتیکی (Minimap Radar):**
   - موقعیت و جهت نگاه تمام بازیکنان و دشمنان با رنگ‌های مشخص روی رادار نمایش داده می‌شود.
5. **جدول امتیازات بلادرنگ (Scoreboard):**
   - با نگه‌داشتن کلید **[TAB]** جدول امتیازات زنده، تعداد کیل‌ها (PvP و PvE)، مرگ‌ها، پینگ و وضعیت بازیکنان نمایش داده می‌شود.
6. **فید اعلام حذف (Kill Feed):**
   - در گوشه بالا-راست تمام رویدادهای حذف بازیکنان و انمی‌ها به شکل انیمیشنی ثبت می‌شود.
7. **سیستم چت تاکتیکی درون بازی (Squad Comms):**
   - با زدن کلید **[ENTER]** کادر چت باز شده و می‌توانید در حین بازی پیام ارسال کنید.

## 🕹️ کلیدهای کنترل

| کلید | عملکرد |
|---|---|
| **W, A, S, D** | حرکت تاکتیکی به جهات مختلف |
| **Mouse Aim** | نشانه‌گیری با لیزر |
| **Left Click** | تیراندازی به انمی‌ها و بازیکنان |
| **Space** | دَش سریع تاکتیکی (Dash) |
| **R** | تعویض خشاب (Reload) |
| **TAB** | مشاهده جدول امتیازات زنده (Scoreboard) |
| **ENTER** | باز کردن چت تاکتیکی |
| **M** | قطع/وصل صدای بازی |
